# PC Tracker (v1.2) — Windows

নিজের **উইন্ডোজ পিসি**র জন্য ব্যক্তিগত ট্র্যাকার। স্ক্রিনে নিজের উইন্ডো আছে (ড্যাশবোর্ড,
সেটিংস, হিস্ট্রি), টাস্কবারের ট্রেতেও বসে থাকে, উইন্ডোজ চালু হলে নিজে থেকেই শুরু হয়, আর সব
আপডেট/কমান্ড একই Telegram চ্যাটে যায় — কোনো সার্ভার লাগে না।

> ⚠️ শুধু **নিজের** পিসিতে ব্যবহার করুন।

| `/screenshot` — পুরো স্ক্রিনের ছবি (মাল্টি-মনিটর) | ✅ |

## ইনস্টল

1. `PCTracker.exe` ডাউনলোড করুন (এক ফাইল, ইনস্টলার লাগে না)।
2. একই ফোল্ডারে রাখুন (যেমন `C:\Apps\PCTracker\PCTracker.exe`) — অটো-স্টার্ট এই পথটাই ব্যবহার করে।
3. ডাবল-ক্লিক → **PC Tracker উইন্ডো** খুলবে, সাথে টাস্কবারের ডান দিকে (সিস্টেম ট্রে) আইকন।
4. প্রথমবার সেটিংস ট্যাব নিজেই খোলা থাকবে:
   - **@BotFather** → `/newbot` → `123456:ABC...` টোকেন কপি
   - নতুন বটকে `/start` পাঠান
   - **@userinfobot** → `/start` → আপনার **Chat ID** কপি
   - টোকেন + Chat ID বসিয়ে **সেভ → টেস্ট মেসেজ**
5. "উইন্ডোজে অটো-স্টার্ট" চেক করা থাকলে লগইনেই নিজে চালু হবে (লগইনে উইন্ডো লুকানো থাকে, ট্রেতে থাকে; আইকনে ডাবল-ক্লিক করলে উইন্ডো ফিরে আসে)।

> **জরুরি:** ফোনের অ্যাপ আর পিসির অ্যাপ **একই বট টোকেনে** চালাবেন না। Telegram-এ এক
> টোকেনে দুটো `getUpdates` চললে কমান্ড একজনের কাছে হারিয়ে যায়। পিসির জন্য আলাদা বট
> বানান (চ্যাট কিন্তু একই থাকবে — একই Chat ID দিন)।

## উইন্ডো

উইন্ডো বন্ধ (X) করলে অ্যাপ বন্ধ হয় না — ট্রেতে চলে যায়। ফিরিয়ে আনতে ট্রে আইকনে
**ডাবল-ক্লিক** করুন বা মেনু থেকে **উইন্ডো দেখান** চাপুন।

- **ড্যাশবোর্ড** — প্রতি সেকেন্ডে লাইভ অবস্থা: অনলাইন/পজ, স্ক্রিন লক, পাওয়ার, নেটওয়ার্ক,
  লোকাল IP, সক্রিয় অ্যাপ, আইডল, আপটাইম, শেষ সিঙ্ক, বট ইউজারনেম। সাথে বাটন: রিফ্রেশ,
  স্ট্যাটাস পাঠান, স্ক্রিনশট পাঠান, ভিডিও, রিং, Telegram টেস্ট, বট চালু/বন্ধ, লোকেশন,
  ট্রেতে লুকান, লগ ফাইল, প্রস্থান।
- **সেটিংস** — টোকেন, Chat ID, হার্টবিট, কোন ঘটনা যাবে, অটো-স্টার্ট, আমার লোকেশন
  (পপআপ ছাড়া, একই উইন্ডোতে)।
- **হিস্ট্রি** — লক/আনলক, চার্জার, ব্যাটারি, নেটওয়ার্ক ঘটনার তালিকা।

## ট্রে মেনু

- **উইন্ডো দেখান** — লুকানো উইন্ডো ফিরিয়ে আনে (ডাবল-ক্লিকও একই কাজ করে)
- **সেটিংস…** — সরাসরি সেটিংস ট্যাব
- **বট চালু** — টগল (পজ করলে মনিটরিং চলবে, নোটিফিকেশন বন্ধ, কিন্তু `/resume` কাজ করবে)
- **Telegram টেস্ট** — `getMe` + টেস্ট মেসেজ
- **লগ ফাইল** — `%APPDATA%\PCTracker\pctracker.log`

## কমান্ড

```
/status      সম্পূর্ণ স্ট্যাটাস
/screenshot  স্ক্রিনের ছবি
/record      স্ক্রিন ভিডিও (৮ সে.; /record 15 দিলে ১৫ সে.)
/location    আপনার সেভ করা লোকেশন
/setlocation লোকেশন সেভ — /setlocation 24.8500,89.3700 বগুড়া
/ring        জোরে সাইরেন (৬০ সে.)
/stopring    সাইরেন বন্ধ
/locks       লক/আনলক হিস্ট্রি
/net         নেটওয়ার্ক ও IP
/sysinfo     সিস্টেম তথ্য
/lock        পিসি লক (কনফার্ম সহ)
/sleep       স্লিপ (কনফার্ম সহ)
/stop        বট বন্ধ · /resume আবার চালু
/help        তালিকা + বাটন
```

**সঠিক লোকেশন:** IP ঠিকানা ISP-এর শহর দেখায় (বগুড়া থেকে ব্যবহার করলেও ঢাকা দেখাতে
পারে)। তাই ফোন থেকে Telegram-এ 📎 → **Location** পাঠান — সেটাই সেভ হয়ে `/location`-এ
দেখাবে, সাথে Google Maps লিংক ও পিন। উইন্ডোর **সেটিংস → আমার লোকেশন**-এ হাতে অক্ষাংশ/
দ্রাঘিমাংশও বসানো যায়।

## পিসি বন্ধ থাকলে?

পিসি পুরোপুরি বন্ধ থাকলে কোনো প্রোগ্রাম (এমনকি Windows-ও) চলতে পারে না — তখন বট উত্তর
দিতে পারবে না, এটা প্রযুক্তিগত সীমা। তবে:

- **পিসি চালু + লগইন হলেই** অ্যাপ নিজে থেকে খুলে যায় (auto-start) এবং বট কানেক্ট হয়।
- Windows বন্ধ/রিস্টার্ট হওয়ার ঠিক আগে Telegram-এ একটি শেষ বার্তা যায় ("পিসি বন্ধ হচ্ছে")।
- অ্যাপ ক্র্যাশ করলেও watchdog নিজে থেকেই পোলিং আবার চালু করে।

## ফাইল কোথায় থাকে

| জিনিস | পথ |
|---|---|
| সেটিংস | `%APPDATA%\PCTracker\config.json` |
| ঘটনার হিস্ট্রি | `%APPDATA%\PCTracker\events.jsonl` (সর্বশেষ ৪০০) |
| লগ | `%APPDATA%\PCTracker\pctracker.log` |
| অটো-স্টার্ট | `HKCU\Software\Microsoft\Windows\CurrentVersion\Run\PCTracker` |

সব ডেটা শুধু আপনার পিসিতে থাকে; Telegram-এ শুধু যেসব মেসেজ/ছবি পাঠানো হয় সেগুলোই যায়।

## বিল্ড (সোর্স থেকে)

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
# আউটপুট: .\PCTracker.exe  (single file, no console)
```

`build.ps1` যা করে: venv তৈরি → `compileall` → `--selftest` → PyInstaller (onefile, windowed)।

## সমস্যা হলে

1. ট্রে আইকনে ডাবল-ক্লিক → **ড্যাশবোর্ড**-এ "🟢 অনলাইন" দেখা যায় কি না দেখুন।
2. না হলে **লগ ফাইল** বোতাম চেপে `%APPDATA%\PCTracker\pctracker.log` খুলুন।
   - `telegram polling armed` + `connected as @...` থাকলে বট ঠিক আছে।
   - `settings file unreadable` থাকলে `config.json` ভাঙা — অ্যাপের **সেটিংস** ট্যাব থেকে
     Token/Chat ID আবার সেভ করুন।
3. কমান্ড কাজ না করলে Telegram-এ `/resume` পাঠান (বট পজ থাকলে শুধু এটাই কাজ করে)।
4. উইন্ডো না দেখলে ট্রে আইকনে ডাবল-ক্লিক করুন, অথবা `PCTracker.exe` বন্ধ করে আবার চালু করুন।

## সীমাবদ্ধতা

- `/location`-এ সেভ করা পিন সঠিক; IP-ভিত্তিক অনুমান ISP-এর কারণে আলাদা শহর দেখাতে পারে।
- `/record` স্ক্রিনের ৮–৩০ সেকেন্ডের GIF পাঠায় (ভিডিও ফাইল নয়); ফ্রেম রেট কম, সাইজ ছোট রাখতে রেজোলিউশন ৯৬০px।
- পিসি বন্ধ থাকলে বট উত্তর দিতে পারে না — চালু হলে auto-start-এ আবার যুক্ত হয়।
- `/ring` সিস্টেম ভলিউম বাড়ায়, পরে আগের ভলিউমে ফেরায় না।
- স্ক্রিনশট প্রাইভেসি-সংবেদনশীল; শুধু নিজের পিসিতে ব্যবহার করুন।
- পিসি স্লিপে গেলে (`/sleep`) Telegram বন্ধ থাকে — জাগানোর পর আবার কানেক্ট হয়।
- Windows Defender প্রথমবার onefile `.exe`-কে "unknown publisher" বলতে পারে —
  More info → Run anyway (কোড সাইনিং সার্টিফিকেট নেই)।
